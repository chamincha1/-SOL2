5.1 준비
 (1) 시뮬레이터를 연다. 기본 환경: G = 1000 W/m², T_amb = 25 ℃, W_s = 1 m/s
     → 모듈온도 T_m ≈ 56.4 ℃ (식 2)
 (2) 감지 지연 = 0.5 s, 20배속, 운전점 = 선택 (실험별로 지정)
 (3) 모든 셀 음영·결함을 초기화한다. => 가장 기본 상태

5.2 실험 A — 4가지 시나리오 × 3가지 방식 비교 (300초 가동)
 (1) 시나리오 선택 (프리셋 버튼)
     A-1 새 분변 1셀 : 25번 셀 음영 60%
     A-2 낙엽 4셀    : 24·25·34·35번 셀 음영 100%
     A-3 구름 그림자 : 18셀(3행×6열) 음영 40%
     A-4 제조결함 1셀: 33번 셀 결함(미세균열형: 광전류 65%, 션트저항 0.8 Ω, 열저항 4 K/W)
 (2) 운전점을 'MPPT'로 두고, [비교 실험 실행] 버튼 → 3방식을 각각 300초 가동
 (3) 운전점을 '단락 근처(최악)'으로 바꿔 (2)를 반복
 (4) 기록: 최고 핫스팟 온도, 130℃ 초과 시간, 최종 출력·손실률, 300초 발전량, 판정
 (5) 위 과정을 4개 시나리오 모두에 대해 수행
=> 정리할거 : MPPT와 단락 근처 두개의 운전점으로 비교실험 한 이유 (최적과 극한의 조건이라는 이유 들어가야 함 / I-V 그래프 이용해서 MPPT정리로 설명
=> 무보호 / 표준 바이패스 다이오드 / 3.2 스마트 바이패스 다이오드 기능설명
=> 물리적 방어 4가지 설명 ( 자연 냉각 / 수동 방열판+PCM / 능동 수냉 스프레이 / 능동 강제 공랭팬) 추후 시뮬레이션에 추가될 예정
=> 새분변, 낙엽, 구름 / vs 내부결함 비교하기 내부결함은 외부 음영이 아닌 셀 내부에서도 방어 방식이 작동하는지 확인하기 위한것 // 새분변 vs 낙엽 vs 구름 / 다른 음영이 결과에 다른 상관관계가 있는지에 대해 정리, 예를 들어 음영 면적이 넓어진다고 해서 전력효율이 떨어지는가? 또는 음영 정도에 따라 전력효율이 변화하는가 에 대한 결과들

=> 비교실험에서 중앙셀음영률 그래프 보는 방법 서술

5.3 실험 B — 음영 정도 스윕 (정상상태 핫스팟 온도)
 (1) 중앙 셀(25번) 1개의 음영률을 0, 5, 10, … 100%로 바꾼다.
 (2) 각 음영률에서 3방식의 정상상태 최고 핫스팟 온도를 구한다.
 (3) 운전점 MPPT와 단락 근처 각각에 대해 수행한다.
 (4) 음영률(x축) – 핫스팟 온도(y축) 그래프를 그리고 85/130/300℃ 기준선을 표시한다.
=> 나만의 기준 다시 세우기
6*9 태양광 위에서 2*3 짜리 음영이 중앙, 그리고 각 네꼭짓점위에 있을때 음영률이 30 60 90% 일때의 전력효율을 실험하는 것으로 함 (음영이 중앙, 네꼭짓점 위에 있을때를 비교하는 이유는 안과 밖을 구별하기 위한 작업임

5.4 실험 C — 감지 지연 시간 영향
 (1) 시나리오 A-1(분변 1셀), MPPT, 스마트 바이패스 선택
 (2) 감지 지연을 0.1, 0.5, 1, 2, 5, 10 s로 바꾸며 300초 가동
 (3) 지연 시간별 최고 핫스팟 온도를 기록한다.
=> 이거 안함. 빼기

5.5 실험 D — 환경 변수 영향 (추가 계획, 안)
 (1) 일사량 100~1000 (100 간격), 기온 −5/10/25/40 ℃, 풍속 0/1/5/10 m/s를
     하나씩만 바꾸며(나머지는 기본값) 시나리오 A-1에서 3방식을 비교한다.
 (2) 연구계획서 3.3.1절 '계절 4구간 × 음영 3종 = 12 시나리오 매트릭스'로 확장한다.
     (※ 이번 시뮬레이터 버전에는 12종 매트릭스·AI(V2G) 모듈은 포함되어 있지 않음)
=> 기존 실험방법대로 하면 경우의 수가 너무 많아져서 각각의 변수의 양끝조건으로 실험하기로 함
=> 1. 일사량이 100이랑 1000일때 실험 , 나머지 기온과 풍속은 초기조건과 동일하게 작용
=> 2. 기온이 -5이랑 25이랑 40일때 실험, 나머지 일사량이랑 풍속은 초기조건과 동일하게 작용
=> 3. 풍속이 0이랑 1, 10일때 실험, 나머지 일사량이랑 기온은 초기조건과 동일하게 작용

저 세 카테고리에 대한 조건을 실행시켜주는 활성화 버튼 만들어주기

5.6 반복 시행 및 통계 (연구계획서 3.8.1절과 대응)
 - 시뮬레이터는 결정론적이므로 같은 조건에서는 같은 값이 나온다.
 - 통계 검정을 위해 풍속·음영 위치·음영률에 난수를 주어 30회 이상 반복한다(안).
   난수 시드는 고정하고 기록한다. (연구계획서 4.4.1절 재현성 원칙)

=> 예를 들어 구름은 한위치에 고정이 아닌 계속 패널위에서 움직이는 위치로 설정하고 일사량도 실제 일출 일몰처럼 고도에 따른 일사량 변화, 온도변화, 풍속변화들을 연속적으로 변화시켜 시뮬레이션의 최대시간인 3600초로 시행해서 이상적인 실험환경이 아닌 실제와 가장 비슷하게 구현할 수 있도록 하는 실험 다시 구상하기

5.7 안전·유의 사항
 - 모든 실험은 가상(수치) 실험이므로 실제 화재·감전 위험은 없다.
 - 시뮬레이션 수치는 가정치이므로 '실제 모듈이 이 온도까지 오른다'는 뜻이 아니다.
